## Query Witness

A Python CLI that finds a small, valid DuckDB table where two SQL queries disagree, then saves it so you can replay the difference.

[Repository](https://github.com/mertsandepalm/query-witness) · [Live demo](https://sandepalm.com/projects/query-witness)
